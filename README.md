> A robust command-line utility built with Bash and PostgreSQL that lets you easily look up chemical elements and their properties right from your terminal! 🔬

### ✨ Features
* **🔍 Smart Search:** Look up elements by entering their atomic number, chemical symbol, or full name.
* **🗄️ Normalized Database:** Features a well-structured relational database with primary/foreign keys and tight data constraints.
* **🧹 Data Cleanup:** Utilizes SQL string manipulation (`TRIM`, `UPPER`, `SUBSTRING`) to ensure perfectly formatted data.

### 🛠️ Tech Stack
* **Language:** Bash Scripting (`.sh`)
* **Database:** PostgreSQL (`.sql`)
* **Version Control:** Git
